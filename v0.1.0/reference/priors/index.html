Priors

Set priors shows these in use.

PracticalBayesianRegression.prior — Function
prior(p; class = :b, coef = "", group = "", dpar = "", nlpar = "", resp = "", lb = -Inf, ub = Inf) -> PriorSpec

One prior, as brms's set_prior / prior(). Pass a vector of them to brm with prior = [...]; every parameter without one keeps its default (see get_prior).

p is one of:

  • a brms prior string: "normal(0, 1)", "student_t(3, 0, 2.5)", "cauchy(0, 1)", "exponential(1)", "gamma(2, 0.1)", "inv_gamma(0.4, 0.3)", "lognormal(0, 1)", "beta(1, 1)", "uniform(0, 10)", "logistic(0, 1)", "double_exponential(0, 1)", "skew_normal(0, 1, 2)", "lkj(2)", "dirichlet(1)", "constant(0.5)" (fixes the parameter), "horseshoe(1)" or "R2D2(0.5, 2)" (shrinkage priors on all coefficients of class :b);
  • a Distributions.jl distribution: Normal(0, 1), Exponential(1), Gamma(2, 10), Cauchy(0, 1), TDist(3), LKJ(2, 2), ...;
  • nothing or "": a flat (improper) prior.

The keywords pick the parameters the prior applies to, as in brms:

  • class: :b (population-level effects), :Intercept, :sd (group-level standard deviations), :cor (group-level correlations), :sigma, :shape, :nu, :phi, :zi, :hu, ... (see get_prior for a model's classes).
  • coef: one coefficient ("x"), else the whole class.
  • group: one grouping factor ("g"), for :sd and :cor.
  • dpar: a distributional parameter's formula ("sigma").
  • nlpar: a non-linear parameter.
  • resp: one response of a multivariate model.
  • lb, ub: bounds on :b coefficients, e.g. lb = 0 for a positive effect.

The most specific matching prior wins.

Examples

priors = [
    prior("normal(0, 1)"; class = :b),
    prior("normal(0, 5)"; class = :b, coef = "x"),
    prior(Exponential(1); class = :sigma),
    prior("student_t(3, 0, 1)"; class = :sd, group = "g"),
    prior(lkj(2); class = :cor),
]
fit = brm(@bf(y ~ x + z + (1 + x | g)), df; prior = priors)

PracticalBayesianRegression.lkj — Function
lkj(eta)

The LKJ prior on a correlation matrix, as brms's lkj(eta), for the correlation classes (:cor, :rescor, ...). eta = 1 is uniform over correlation matrices; larger values favour weaker correlations.

prior(lkj(2); class = :cor)
source
PracticalBayesianRegression.dirichlet — Method
dirichlet(alpha)

The symmetric Dirichlet prior on a simplex, as brms's dirichlet(alpha): the prior of the simplexes of monotonic effects (class :simo). Called without a positional argument, dirichlet() is the response family.

prior(dirichlet(2); class = :simo)

PracticalBayesianRegression.PriorSpec — Type
PriorSpec

One row of a prior table: a prior and the parameters it applies to (class, coefficient, group, distributional parameter, response, bounds). Made by prior; get_prior and prior_summary return them too.

PracticalBayesianRegression.get_prior — Function
get_prior(formula, data; family=gaussian(), data2=nothing) -> PriorTable

The parameter classes of a model and the default prior of each, before fitting — brms's get_prior() / default_prior(). Set priors on any row with prior and pass them to brm.

The full prior table the model would be fitted with, as brms's validate_prior(): your priors where they apply, defaults elsewhere. A prior whose coef or group matches nothing in the model does not appear.
