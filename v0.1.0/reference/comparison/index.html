Model comparison

Cross-validation

PracticalBayesianRegression.loo — Function
loo(fit; moment_match = false, k_threshold = 0.7) -> LOOResult

Approximate leave-one-out cross-validation by Pareto-smoothed importance sampling (Vehtari, Gelman & Gabry 2017), as brms's loo.

Observations with Pareto k above 0.7 make the estimate unreliable. With moment_match = true, the draws are adapted for each observation whose k exceeds k_threshold (Paananen et al. 2021), as brms's loo(fit, moment_match = TRUE); kfold refits the model instead.

loo(fit)
loo_compare("full" => fit1, "reduced" => fit2)

PracticalBayesianRegression.waic — Function
waic(fit) -> LOOResult

The widely applicable information criterion, as brms's waic.

source
PracticalBayesianRegression.kfold — Function
kfold(fit; K=10, seed=1, kwargs...) -> LOOResult

K-fold cross-validation, as brms's kfold: refit K times leaving one fold out, and score the held-out observations by their log predictive density. Extra keywords go to the refits (e.g. chains=2).

source
PracticalBayesianRegression.LOOResult — Type
LOOResult

The result of loo, waic or kfold. Fields: elpd (the expected log predictive density) and its standard error se; p (the effective number of parameters) and p_se; pointwise, the elpd of each observation; and for PSIS-LOO, pareto_k, each observation's Pareto k diagnostic. Displaying it prints brms's table, including the information criterion -2 elpd.

source
PracticalBayesianRegression.loo_compare — Function
loo_compare(fits...; criterion=loo) -> Vector of (name, elpd_diff, se_diff)

Compare models by expected log predictive density, as loo::loo_compare: differences are relative to the best model, with the SE of the paired pointwise differences. Pass name => fit pairs to label them.

source
PracticalBayesianRegression.loo_predict — Function
loo_predict(fit; type = :mean, probs = [0.025, 0.975], rng = Random.default_rng())

Leave-one-out posterior predictive summaries by Pareto-smoothed importance sampling, as brms's loo_predict: each observation's predictive distribution, weighted as if that observation had been left out of the fit.

type = :mean or :var returns one value per observation; type = :quantile returns an observations x probs matrix.

See also loo_epred, loo_linpred, loo.

source
PracticalBayesianRegression.loo_epred — Function
loo_epred(fit; type = :mean, probs = [0.025, 0.975])

Leave-one-out summaries of the expected response (posterior_epred), weighted by PSIS as in loo_predict. Not available for ordinal and categorical models.

source
PracticalBayesianRegression.loo_linpred — Function
loo_linpred(fit; type = :mean, probs = [0.025, 0.975], dpar = :mu, transform = false)

Leave-one-out summaries of the linear predictor of dpar (posterior_linpred), weighted by PSIS as in loo_predict. transform = true applies the inverse link.

Model weights and averaging

PracticalBayesianRegression.model_weights — Function
model_weights(fits...; weights = :stacking, criterion = loo) -> Vector{Float64}

Weights for averaging the predictions of several models, from their pointwise leave-one-out log predictive densities, as brms's model_weights:

  • :stacking: stacking of predictive distributions (Yao et al. 2018);
  • :pseudobma: pseudo-BMA+ weights with the Bayesian bootstrap;
  • :loo: weights proportional to exp(elpd_loo).

criterion can be waic instead of loo.

w = model_weights(fit1, fit2; weights = :stacking)
source

posterior_average(fits...; variables, weights = :stacking, ndraws = 4000) -> Dict

brms posterior_average: draws of variables (present in every model) mixed across the models in proportion to the model weights.

brms pp_average: posterior predictive (or method = posterior_epred) draws mixed across models in proportion to the model weights (draws x observations).

Marginal likelihood

PracticalBayesianRegression.bridge_sampler — Function
bridge_sampler(fit; maxiter = 1000, tol = 1e-10, rng = Xoshiro(1)) -> log marginal likelihood

brms / bridgesampling's estimator: a multivariate normal proposal fitted to the first half of the (unconstrained) draws, the iterative Meng & Wong scheme on the second half against as many proposal draws.
