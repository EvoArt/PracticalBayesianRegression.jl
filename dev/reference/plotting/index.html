Plotting and export

The plotting functions need a plotting package to be loaded: CairoMakie (or another Makie backend), PlotlyLight or UnicodePlots. With more than one loaded, pass backend = :makie, :plotly or :unicode; otherwise they use the first available in that order. See Plot a fit.

PracticalBayesianRegression.pp_check — Function
pp_check(fit; type=:dens_overlay, ndraws=50, backend=nothing, kwargs...)

Posterior predictive check, as brms's pp_check (bayesplot's ppc_*): type is :dens_overlay (default), :hist, :ecdf_overlay, :stat (stat=mean by default) or :bars (discrete responses). Needs a plotting extension: load PlotlyLight (lightest install, interactive HTML), Makie (e.g. using CairoMakie, for static publication figures) or UnicodePlots (terminal).

PracticalBayesianRegression.to_inferencedata — Function

Convert a fit to an InferenceObjects.InferenceData (the format ArviZ.jl works with) with posterior, samplestats, observeddata and, optionally, posteriorpredictive and loglikelihood groups. Needs using InferenceObjects (or ArviZ).
