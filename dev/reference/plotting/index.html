Plotting and export

The plotting functions draw with PracticalBayesPlot, a dependency, unless CairoMakie (or another Makie backend), PlotlyLight or UnicodePlots is loaded. Pass backend = :makie, :plotly, :unicode or :pbp to pick one; otherwise they use the first loaded in that order. See Plot a fit.

PracticalBayesianRegression.pp_check — Function
pp_check(fit; type=:dens_overlay, ndraws=50, backend=nothing, kwargs...)

Posterior predictive check, as brms's pp_check (bayesplot's ppc_*): type is :dens_overlay (default), :hist, :ecdf_overlay, :stat (stat=mean by default) or :bars (discrete responses).

Draws with PracticalBayesPlot (an SVG figure, shown inline in VS Code, Jupyter and Pluto) unless a plotting package is loaded: Makie (e.g. using CairoMakie, for static publication figures), PlotlyLight (interactive HTML) or UnicodePlots (terminal). backend picks one of :pbp, :makie, :plotly or :unicode.

PracticalBayesianRegression.save_plot — Function
save_plot(path, fig; standalone = false) -> path

Write a figure from pp_check, plot_effects, trace_plot or residual_plot (the default PracticalBayesPlot backend) to path. The extension picks the format:

  • .svg: an SVG image; .html: a page showing it;
  • .tex: a TikZ picture for \input into a LaTeX document, its text set by LaTeX in the document's font (needs \usepackage{tikz});
  • .typ: a CeTZ drawing for #include into a Typst document, its text set by Typst.

standalone = true makes a .tex or .typ file a document that compiles on its own. It is PracticalBayesPlot's save, so this works without adding PracticalBayesPlot to your environment. Figures from Makie are saved with Makie's own save.

source
PracticalBayesianRegression.embed — Function
embed(fig) -> Embedded

A figure for a Quarto (or other Pandoc) document: the value of a code cell that is embed(pp_check(fit)) shows the figure as SVG in HTML output, as a TikZ picture in a LaTeX PDF and as a CeTZ drawing in a Typst PDF. In the PDFs the figure is typeset with the document, its text in the document's font.

A LaTeX PDF needs TikZ loaded, in the document's header:

format:
  pdf:
    include-in-header:
      text: \usepackage{tikz}

Typst output needs nothing: the figure imports CeTZ itself (Typst 0.15 or later). See A report with Quarto.

source
PracticalBayesianRegression.Embedded — Type
Embedded

A figure or table in three forms, for a document that Pandoc renders (Quarto, R Markdown): HTML, LaTeX and Typst. A code cell whose value is an Embedded puts all three into the document as raw blocks, and each output format keeps its own: the web page gets the SVG or HTML table, a LaTeX PDF the TikZ picture or booktabs table, a Typst PDF the CeTZ drawing or Typst table. Made by embed and by summary_table(...; format = :embed).

Tables for reports

The posterior summary and the priors as LaTeX, Typst, Markdown or HTML tables. See A report with Quarto and Put results in a LaTeX or Typst document.

PracticalBayesianRegression.summary_table — Function
summary_table(fit; format = :latex, prob = 0.95, digits = 2, diagnostics = true) -> String
summary_table(path, fit; kwargs...)

The posterior summary of fit as a table for a report: the rows and sections the REPL summary shows (group-level standard deviations and correlations, regression coefficients, further distributional parameters), with brms's columns Estimate, Est.Error, the central prob interval and, with diagnostics = true, Rhat, Bulk_ESS and Tail_ESS.

format is :latex (a booktabs tabular; load \usepackage{booktabs}), :typst (a table), :markdown, :html, or :embed for a Quarto (or other Pandoc) document: an Embedded that a code cell shows as the HTML table in a web page, the booktabs table in a LaTeX PDF and the Typst table in a Typst PDF, shrunk to the text width in the PDFs if it is wider. With a path, the table is written to that file and the extension picks the format (.tex, .typ, .md, .html); the path is returned.

The table has no caption or float, so the document places it:

\begin{table}\centering
  \caption{Posterior summary}\input{summary.tex}
\end{table}
#figure(include "summary.typ", caption: [Posterior summary])

Numbers have digits decimals; a row whose estimate and interval are all below 0.005 in magnitude switches to scientific notation, as in the REPL.

PracticalBayesianRegression.prior_table — Function
prior_table(fit_or_info; format = :latex) -> String
