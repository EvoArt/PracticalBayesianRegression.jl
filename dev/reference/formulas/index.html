Formulas

A model formula is written with @bf (bare names) or bf (a string, as in R). The syntax is brms's; the table summarises it.

TermMeaning
y ~ x + zpopulation-level effects of x and z, with an intercept
y ~ 0 + x, y ~ x - 1no intercept
x * z, x:z, x & zmain effects and interaction; interaction only
log(x), I(x^2), poly(x, 2), ns(x, 3), bs(x, 4)transformed predictors and spline bases
offset(log(t))a term with coefficient fixed at 1
(1 + x | g)correlated group-level intercepts and slopes
(1 + x || g)uncorrelated group-level effects
(1 | g1:g2), (1 | g1/g2)interaction of grouping factors; nesting
(1 | p | g)group-level effects correlated across formulas sharing the ID p
(1 | gr(g, ...)), (1 | mm(g1, g2))grouping options; multi-membership
mo(x), cs(x)monotonic effect of an ordinal predictor; category-specific effect
me(x, sdx), mi(x)predictor measured with error; predictor with missing values
s(x), t2(x, z), gp(x)smooths, tensor-product smooths, Gaussian processes
ar(), ma(), arma(), cosy(), unstr(), fcor(M)temporal and other residual correlation structures
sar(W), car(W, gr = g)spatial terms
y | trials(n), weights(w), se(s), cens(c), trunc(lb = 0), rate(t), mi(), thres(3), dec(d), subset(s), vreal(v), vint(n)addition terms on the response
sigma ~ z, shape ~ z, ...formulas for distributional parameters
PracticalBayesianRegression.@bf — Macro
@bf(formula, dpar_formulas...) -> BrmsFormula
@bf(formula, dpar_formulas..., nl = true)
@bf(formula, dpar_formulas..., center = false)

Write a model formula in brms syntax with bare names. The first formula is response ~ terms; each further formula dpar ~ terms models one distributional parameter of the family. Functions in the formula are looked up in the module where the macro is used. nl and center are as in bf.

Population-level terms follow R's rules: x + z, x * z (main effects and interaction), x:z or x & z (interaction only), 0 + x or x - 1 (no intercept), log(x), I(x^2), poly(x, 2), ns(x, 3), bs(x, 4), offset(log(t)). Julia parses : more loosely than +, so write (a + b):c as a:c + b:c.

Group-level terms: (1 + x | g) (correlated), (1 + x || g) (uncorrelated), (1 | g1:g2), (1 | g1/g2), (1 | p | g) (correlated across formulas), (1 | gr(g, by = h, cor = false, dist = "student", cov = A)), (1 | mm(g1, g2, weights = cbind(w1, w2))).

Special terms: mo(x), cs(x), me(x, sdx), mi(x), s(x), t2(x, z), gp(x), ar(), ma(), arma(), cosy(), unstr(), fcor(M), sar(W), car(W, gr = g).

Addition terms on the response: y | trials(n), weights(w), se(s), cens(c), trunc(lb = 0), rate(t), mi(), thres(3), dec(d), subset(s), vreal(v), vint(n), combined with +.

Examples

@bf(y ~ x + (1 + x | g))
@bf(y ~ x, sigma ~ x)                            # distributional model
@bf(y ~ a * exp(-b * x), a ~ 1, b ~ 1 + (1 | g), nl = true)
@bf(y1 ~ x) + @bf(y2 ~ x) + set_rescor(false)    # multivariate model

See bf for the keywords and for formulas given as strings.

PracticalBayesianRegression.bf — Function
bf(formula, dpar_formulas...; nl = false, center = true, mod = Main) -> BrmsFormula

Parse a model formula written in brms syntax and given as a string (or a quoted expression). Strings let you copy formulas to and from R unchanged; in Julia code, @bf does the same without quotes.

The first formula is response ~ terms; each further formula dpar ~ terms models one distributional parameter of the family (sigma ~ z) or, with nl = true, one non-linear parameter. See @bf for the terms.

Keywords

  • nl: the main formula's right-hand side is a non-linear Julia expression in parameters, each given its own formula (bf("y ~ a * exp(-b * x)", "a ~ 1", "b ~ 1"; nl = true)). The expression is compiled at run time, so inside a function call brm through Base.invokelatest.
  • center: centre the population-level predictors, as brms does by default; with center = false the Intercept is the intercept at zero predictors.
  • mod: the module in which functions used in the formula (log(x), myfun(x)) and named matrices are looked up. Inside a package, pass mod = @__MODULE__.

Examples

bf("y ~ x + (1 | g)")
bf("y ~ x + (1 | g)", "sigma ~ x")              # distributional model
bf("count | trials(n) ~ treatment + (1 | site)")

PracticalBayesianRegression.@lf — Macro
@lf(dpar_formulas...)

The macro form of lf: @bf(y ~ x) + @lf(sigma ~ z) is @bf(y ~ x, sigma ~ z).

source
PracticalBayesianRegression.lf — Function
lf(dpar_formulas...)

Formulas for distributional parameters, given as strings, to add to a model formula with +, as brms's lf(). bf("y ~ x") + lf("sigma ~ z") is the same model as bf("y ~ x", "sigma ~ z"). Non-linear models take all their formulas in bf itself.

See also @lf.

source
PracticalBayesianRegression.set_rescor — Function
set_rescor(flag=true)

Residual correlations between the responses of a multivariate model (gaussian responses), as brms's set_rescor; add it to the formula with +.

source
PracticalBayesianRegression.set_mecor — Function
set_mecor(flag = true)

Whether the latent values of two or more me() terms are correlated, as brms's set_mecor. Correlated latents are the default; add set_mecor(false) to the formula with + for independent ones:

@bf(y ~ me(x1, sdx1) + me(x2, sdx2)) + set_mecor(false)
source
PracticalBayesianRegression.BrmsFormula — Type
BrmsFormula

A parsed model formula, made by @bf or bf. Add lf formulas or set_mecor to it with +; adding two formulas gives a multivariate MVFormula.

source
PracticalBayesianRegression.MVFormula — Type
MVFormula

Several BrmsFormulas fitted jointly. Build it with + (@bf(y1 ~ x) + @bf(y2 ~ z)), from @bf(mvbind(y1, y2) ~ x), and add set_rescor(true/false) to choose residual correlations (default: on when every response is gaussian, as brms).
