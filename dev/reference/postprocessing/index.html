Posterior summaries and predictions

Parameters

PracticalBayesianRegression.posterior_summary — Function
posterior_summary(fit; variables = variables(fit), prob = 0.95) -> Vector{SummaryRow}

Summaries of the posterior draws of variables, as brms's posterior_summary: one row per parameter with fields variable, estimate (posterior mean), est_error (posterior standard deviation), lower and upper (the central prob interval), rhat, bulk_ess and tail_ess.

rows = posterior_summary(fit; variables = ["b_x", "sigma"])
rows[1].estimate

PracticalBayesianRegression.fixef — Function
fixef(fit; prob=0.95) -> Vector{SummaryRow}

Population-level ("fixed") effects of the mean, named without the b_ prefix, as brms's fixef().

PracticalBayesianRegression.ranef — Function
ranef(fit; prob=0.95) -> Dict{String, Dict{String, Vector{SummaryRow}}}

Group-level effects, as brms's ranef: ranef(fit)["g"]["Intercept"] is one row per level of g (the row's variable is the level).

source
PracticalBayesianRegression.group_coef — Function
group_coef(fit; prob=0.95)

Population-level plus group-level effects per level — brms's coef() (named differently here so as not to clash with StatsAPI.coef, which returns the population-level posterior means). A coefficient that varies by g gets b_coef + r_g[level, coef]; one that does not is reported as the population-level value for every level.

source
PracticalBayesianRegression.VarCorr — Function
VarCorr(fit; prob=0.95) -> Dict{String, NamedTuple}

Group-level standard deviations, correlations and covariances, as brms's VarCorr(): VarCorr(fit)["g"].sd (one row per coefficient), .cor and .cov (one row per pair, from the draws of sda sdb cor_ab). A model with a scalar sigma also gets "residual__" (its sd).

source
PracticalBayesianRegression.posterior_interval — Function
posterior_interval(fit; prob = 0.95) -> Dict{String, Tuple{Float64, Float64}}

The central prob posterior interval of every parameter, as brms's posterior_interval: variable => (lower, upper).

source
PracticalBayesianRegression.hypothesis — Function
hypothesis(fit, h; alpha=0.05)

Test hypotheses about the parameters, as brms's hypothesis: h is a string such as "x > 0", "x - z = 0", "2 * x = Intercept" (a vector of strings tests several). Population-level effects may be named without their b_ prefix. For one-sided hypotheses the evidence ratio is P(H)/P(not H) under the posterior and the interval is the one-sided 90% (alpha = 0.05 each side) as in brms.

source
PracticalBayesianRegression.HypothesisResult — Type
HypothesisResult

One tested hypothesis: the posterior of lhs - rhs summarised (estimate, error, central interval), and for one-sided hypotheses the evidence ratio P(H) / P(not H) and the posterior probability P(H).

Effects and smooths

PracticalBayesianRegression.conditional_effects — Function
conditional_effects(fit, effect; resolution=100, prob=0.95, method=:epred,
                    conditions=nothing, re_formula=:none)

The data behind brms's conditional_effects plots: the response (or linear predictor, method=:linpred) as a function of effect with every other predictor held at its mean (numeric) or reference level (factor), group-level effects excluded by default (brms's re_formula = NA). effect is a column name (:x), or a pair :x => :g for an interaction (one curve per level of g, or at mean ± sd for a numeric g).

Returns a NamedTuple of vectors: the grid columns, estimate, lower, upper. The plotting extensions draw it.

source

posterior_smooths(fit; smooth = "s(x)", newdata = nothing, dpar = :mu) -> draws x observations

brms posterior_smooths: the term's contribution to the (link-scale) predictor of dpar, per draw, without the intercept or other terms.

PracticalBayesianRegression.bayes_R2 — Function
bayes_R2(fit; prob=0.95) -> SummaryRow

Bayesian R² (Gelman, Goodrich, Gabry & Vehtari 2019), as brms's bayes_R2: per draw, var(E[y]) / (var(E[y]) + var(y - E[y])).
