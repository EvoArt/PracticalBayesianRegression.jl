Families

A family is the distribution of the response. Each constructor takes an optional link for the mean parameter mu; the other parameters use fixed links (log for standard deviations, shapes and precisions, logit for probabilities). Model any of them with its own formula, e.g. @bf(y ~ x, sigma ~ x). Choose a family and link gives an overview.

Continuous responses

PracticalBayesianRegression.gaussian — Function
gaussian(; link = :identity)

Normal distribution for continuous responses. Parameters: mu (mean) and sigma (standard deviation).

Links for mu: identity (default), log, inverse, softplus, squareplus, logit, probit, probit_approx, cloglog, cauchit, softit.

Examples

brm(@bf(y ~ x), data; family = gaussian())
brm(@bf(y ~ x, sigma ~ x), data; family = gaussian())   # sigma varies with x
source
PracticalBayesianRegression.student — Function
student(; link = :identity)

Student-t distribution for continuous responses with heavy tails. Parameters: mu, sigma (scale) and nu (degrees of freedom, above 1).

Links for mu: identity (default), log, inverse, softplus, squareplus, logit, probit, probit_approx, cloglog, cauchit, softit.

source
PracticalBayesianRegression.skew_normal — Function
skew_normal(; link = :identity)

Skew-normal distribution for continuous responses, in brms's parameterisation: mu (the mean), sigma (the standard deviation) and alpha (skewness).

source
PracticalBayesianRegression.exgaussian — Function
exgaussian(; link = :identity)

Exponentially modified Gaussian distribution, often used for reaction times. Parameters: mu (the mean), sigma (the normal component's standard deviation) and beta (the exponential component's scale).

source
PracticalBayesianRegression.gen_extreme_value — Function
gen_extreme_value(; link = :identity)

Generalised extreme value distribution, for maxima or minima. Parameters: mu (location), sigma (scale) and xi (shape). As in brms, xi is bounded so that every observation lies inside the distribution's support.

source
PracticalBayesianRegression.asym_laplace — Function
asym_laplace(; link = :identity)

Asymmetric Laplace distribution, for quantile regression. Parameters: mu (the quantile-th quantile of the response), sigma (scale) and quantile (in (0, 1)). Fix the quantile with a constant prior, e.g. prior("constant(0.9)"; class = :quantile).

Links for mu: identity (default), log, inverse, softplus, squareplus.

Positive responses

PracticalBayesianRegression.lognormal — Function
lognormal(; link = :identity)

Lognormal distribution for positive responses: log(y) is normal with mean mu and standard deviation sigma.

PracticalBayesianRegression.shifted_lognormal — Function
shifted_lognormal(; link = :identity)

Lognormal distribution shifted to the right by ndt, often used for reaction times. Parameters: mu, sigma (as in lognormal) and ndt (the shift, between 0 and the smallest response).

PracticalBayesianRegression.gammafamily — Function
gammafamily(; link = :log)

Gamma distribution for positive responses, brms's Gamma() (the name Gamma belongs to Distributions.jl). Parameters: mu (the mean) and shape.

The default link is log; brms's Gamma() defaults to inverse, so pass link = :inverse to reproduce a brms model that relies on that default.

Links for mu: log (default), identity, inverse, softplus, squareplus.

Binary and binomial responses

PracticalBayesianRegression.bernoulli — Function
bernoulli(; link = :logit)

Bernoulli distribution for binary responses coded 0 and 1. Parameter: mu (the probability of a 1).

Base.binomial — Method
binomial(; link = :logit)

Binomial distribution for the number of successes out of n trials; give the trials with y | trials(n). Parameter: mu (the success probability). binomial() is a method of Base.binomial, so it needs no import.

Links for mu: logit (default), probit, cloglog, probit_approx, cauchit, softit, identity, log.

Examples

PracticalBayesianRegression.beta_binomial — Function
beta_binomial(; link = :logit)

Beta-binomial distribution: a binomial with extra variation between observations. Give the trials with y | trials(n). Parameters: mu (mean success probability) and phi (precision).

Links for mu: logit (default), probit, cloglog, probit_approx, cauchit, softit, identity.

Counts

PracticalBayesianRegression.poisson — Function
poisson(; link = :log)

Poisson distribution for counts. Parameter: mu (the mean). Use y | rate(t) for an exposure t.

Links for mu: log (default), identity, sqrt, softplus, squareplus.

Examples

source
PracticalBayesianRegression.negbinomial — Function
negbinomial(; link = :log)

Negative binomial distribution for overdispersed counts. Parameters: mu (the mean) and shape; the variance is mu + mu^2 / shape.

Links for mu: log (default), identity, sqrt, softplus, squareplus.

See also negbinomial2.

source
PracticalBayesianRegression.negbinomial2 — Function
negbinomial2(; link = :log)

Negative binomial distribution parameterised by mu (the mean) and sigma = 1 / shape, so that sigma near 0 approaches the Poisson.

Links for mu: log (default), identity, sqrt, softplus, squareplus.

source
PracticalBayesianRegression.geometric — Function
geometric(; link = :log)

Geometric distribution for counts: a negative binomial with shape = 1. Parameter: mu (the mean).

Links for mu: log (default).

Discrete Weibull distribution for counts. Parameters: mu (in (0, 1)) and shape.

Ordinal and categorical responses

PracticalBayesianRegression.cumulative — Function
cumulative(; link = :logit)

Cumulative ordinal model (ordered logit with the default link). The response is an ordered category: integers 1, 2, ..., or a categorical vector, whose levels are used in their own order (sorted, for plain strings). Parameters: mu (the latent predictor) and the ordered thresholds, reported as b_Intercept[1], b_Intercept[2], ... A formula disc ~ ... models the discrimination.

Links: logit (default), probit, probit_approx, cloglog, cauchit, softit.

source
PracticalBayesianRegression.sratio — Function
sratio(; link = :logit)

Stopping-ratio (sequential) ordinal model. Response and parameters as for cumulative; cs(x) gives category-specific effects.

Links: logit (default), probit, probit_approx, cloglog, cauchit.

source
PracticalBayesianRegression.cratio — Function
cratio(; link = :logit)

Continuation-ratio ordinal model. Response and parameters as for cumulative; cs(x) gives category-specific effects.

Links: logit (default), probit, probit_approx, cloglog, cauchit.

source
PracticalBayesianRegression.acat — Function
acat(; link = :logit)

Adjacent-category ordinal model. Response and parameters as for cumulative; cs(x) gives category-specific effects.

Links: logit (default), probit, probit_approx, cloglog, cauchit, softit.

source
PracticalBayesianRegression.hurdle_cumulative — Function
hurdle_cumulative(; link = :logit)

Ordinal responses with a hurdle: 0 with probability hu, otherwise a cumulative-model category 1, 2, ... (see cumulative).

Links: logit (default), probit, probit_approx, cloglog, cauchit, softit.

source
PracticalBayesianRegression.categorical — Function
categorical(; link = :logit)

Categorical (multinomial logit) model for an unordered response with K categories, coded 1, ..., K or as a categorical vector. The first category is the reference; categories 2 to K get predictors mu2, ..., muK, which share the main formula unless given their own (mu3 ~ z).

source

Multi-category responses

PracticalBayesianRegression.multinomial — Function
multinomial(; link = :logit)

Multinomial distribution for counts in K categories, with the response given as columns: cbind(a, b, c) ~ x. The first column is the reference category; each other category c gets its own predictor muc, which shares the main formula unless given its own (muc ~ z).

source
PracticalBayesianRegression.dirichlet — Method
dirichlet(; link = :logit)

Dirichlet distribution for proportions in K categories that sum to one, with the response given as columns: cbind(a, b, c) ~ x. As in multinomial, every category but the first gets a predictor; phi is the precision.

source
PracticalBayesianRegression.logistic_normal — Function
logistic_normal(; link = :identity)

Logistic-normal distribution for proportions in K categories, with the response given as columns: cbind(a, b, c) ~ x. The log ratios of each category to the first are multivariate normal, with a mean muc and scale sigmac per non-reference category c and a correlation matrix lncor.

Von Mises distribution for angles in [-π, π]. Parameters: mu (the mean direction) and kappa (concentration).

PracticalBayesianRegression.wiener — Function
wiener(; link = :identity)

brms's wiener() family (drift-diffusion); the response needs | dec(d).

source
PracticalBayesianRegression.cox — Function
cox(; link = :log)

Cox proportional hazards model for positive event times, as brms's cox(): the baseline hazard is a cubic M-spline in time with simplex weights sbhaz. Mark right-censored times with time | cens(c) ~ x, where c is 0 for an event and 1 for a right-censored time.

source
PracticalBayesianRegression.mixture — Function
mixture(fams...; order=nothing)

A finite mixture of families, as brms's mixture(): mixture(gaussian(), gaussian()), or with family names, mixture(:gaussian, :student). order defaults to ordering the mean intercepts when every component is the same family (brms's order = "mu"), which identifies the components.

PracticalBayesianRegression.custom_family — Function
custom_family(name; dpars = (:mu,), links = (:identity,), lb = nothing, ub = nothing,
              type = :real, ll, rand = nothing, mean = nothing)

A user-defined response distribution, as brms's custom_family, with its log density written as a Julia function instead of Stan code.

  • dpars: the parameter names; the first must be :mu.
  • links: one link per parameter (:identity, :log, :logit, or any link a built-in family uses for mu).
  • lb, ub: per-parameter bounds, nothing for none. A :log link has lower bound 0 and a :logit link the interval (0, 1) unless given.
  • type: :real or :int, the type of the response.
  • ll(y, mu, other_dpars..., vars...): the log density of one observation at the natural scale of each parameter. vars are the values of the vreal(...) / vint(...) addition terms for that observation. ll is differentiated with dual numbers, so it must accept any Real type (plain Julia code, SpecialFunctions.jl and Distributions.jl logpdfs do).
  • rand(rng, mu, other_dpars...) and mean(mu, other_dpars...): optional, for posterior_predict and posterior_epred.

Parameters without a formula get flat priors, as in brms; set proper ones with prior.

Examples

normal2 = custom_family("normal2"; dpars = (:mu, :sigma), links = (:identity, :log),
                        ll = (y, mu, sigma) -> -log(sigma) - (y - mu)^2 / (2 * sigma^2),
                        rand = (rng, mu, sigma) -> mu + sigma * randn(rng),
                        mean = (mu, sigma) -> mu)
fit = brm(@bf(y ~ x), df; family = normal2,
          prior = [prior("exponential(1)"; class = :sigma)])
source
PracticalBayesianRegression.brmsfamily — Function
brmsfamily(name; link = nothing)

A family by its brms name, given as a string or symbol: "gaussian", "gamma", "beta", "inverse.gaussian", "zero_inflated_poisson", and so on for every family in this package, or a mixture such as "mixture(gaussian, student)". link is a link name; nothing takes the family's default.

brmsfamily("gamma"; link = "inverse")     # brms's Gamma()
