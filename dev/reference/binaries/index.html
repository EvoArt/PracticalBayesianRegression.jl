Model binaries

See Build a model binary.

PracticalBayesianRegression.build_binary — Function
build_binary(formula, data; family=gaussian(), prior=PriorSpec[], output="model",
             name="model", juliac=nothing, cc=nothing, verbose=true) -> executable path

Compile a model into a standalone executable that refits it to any CSV file with the same columns, much as a CmdStan executable refits its model to new data:

$ model/bin/model --data new.csv --output draws.csv --chains 4 --seed 1

data is example data: it fixes which columns are numeric and which are factors, and the build checks the compiled model against brm on it. The executable writes the draws as CSV with brms parameter names and prints a summary table; --help lists its options. It needs no Julia installation: distribute the whole output directory.

Building needs Julia 1.12 or later, a C compiler and JuliaC: by default the juliac app on the PATH (pkg> app add JuliaC); otherwise pass juliac as a Cmd, e.g. $`julia --project=/path/to/env -e "using JuliaC; JuliaC.main(ARGS)" --`$. cc sets the C compiler command. A run with --seed s gives the same draws as brm(formula, data; family, prior, seed = s).

Not every model can be compiled yet; an unsupported feature raises an ArgumentError that names it (see model_recipe).

PracticalBayesianRegression.model_recipe — Function
model_recipe(formula, data; family=gaussian(), prior=PriorSpec[]) -> (recipe, atoms)

Build the model once with the front end and extract its ModelRecipe. Throws an ArgumentError naming every feature a recipe does not support yet, and verifies that re-assembling data from the recipe reproduces build_model exactly. atoms (the front end's atoms, in recipe order) is what code generation for a model binary needs.

PracticalBayesianRegression.ModelRecipe — Type
ModelRecipe

The structure of a model, without its data: what assemble needs to build the GLMDensity for any data with the right columns. Made by model_recipe.

source
PracticalBayesianRegression.assemble — Function
assemble(recipe, atomvals) -> (GLMDensity, rows)

The model's density for new data, given every atom of the recipe evaluated on it. rows are the complete cases used. Trimmable: this is what a model binary runs.

PracticalBayesianRegression.read_csv — Function
read_csv(path; delim = ',') -> DataTable

Read a CSV file with a header row, as a model binary does. Quoted fields follow RFC 4180; NA and empty cells are missing, as in R's read.csv.

source
PracticalBayesianRegression.DataTable — Type
DataTable

A CSV file read by read_csv: its column names, and for each column the cells as written, their numeric values (NaN where a cell is not a number) and which cells are missing (NA or empty).
